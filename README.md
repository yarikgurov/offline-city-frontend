# OFFLINE CITY — Frontend

Браузерная PWA-игра-детектив. Кейс: «Офлайн-город. PWA не спасает. Работа без сети».

## Запуск

Требует запущенного бэкенда на `http://localhost:3000`.

```bash
npx http-server -p 5500 -c-1
```

Открой в браузере: `http://localhost:5500`

## Страницы (локации)

| Страница | Описание |
|---|---|
| Главная | Состояние системы, кнопки Новое дело / Продолжить / Закрыть |
| Адм. панель | Геймплей: события смен, выбор решений |
| Журнал ошибок | Системные логи (INFO/WARNING/ERROR) + журнал действий |
| Архив данных | База собранных улик |

## Структура

```
frontend/
├── index.html      — 4 страницы с навигацией
├── app.js          — логика игры, запросы к API бэкенда
├── style.css       — тёмная киберпанк-тема
├── sw.js           — намеренно сломанный Service Worker (по сюжету)
├── manifest.json   — PWA-манифест
└── assets/
    └── backgrounds/ — фоны для каждой смены
```

## Геймплей

1. Нажми «Новое дело» — откроется Адм. панель
2. Решай инциденты каждой смены (10 смен, разные механики)
3. Правильные решения добавляют улики в Архив данных
4. Следи за системными ошибками в Журнале ошибок
5. Финал: собери все улики и получи ранг «Мастер-детектив»
